# Exercícios Alura 📚

Este repositório contém as minhas resoluções de exercícios práticos e desafios propostos durante os cursos da plataforma [Alura](https://www.alura.com.br/). O objetivo principal deste projeto é praticar, documentar e consolidar a minha evolução na aprendizagem de programação.

## 🚀 Tecnologias Utilizadas

* **Java**

## 📁 Estrutura do Projeto

O código-fonte encontra-se na diretoria `src/`, organizado por pacotes que representam os diferentes conceitos abordados:

* **`colecoesestreams/`**: Práticas com listas, conjuntos, mapas e a API de Streams.
* **`condicionais/`**: Estruturas de controlo de fluxo e tomadas de decisão.
* **`data/`**: Trabalhando com datas, horas e fusos horários.
* **`encapsulamento/`**: Aplicação do conceito de encapsulamento em Orientação a Objetos.
* **`heranca/`**: Reutilização de código e estruturação de superclasses.
* **`oo/`**: Fundamentos de Orientação a Objetos (classes, atributos, métodos e objetos).
* **`repeticao/`**: Laços de repetição e iterações.
* **`stringregex/`**: Manipulação de cadeias de caracteres e extração de dados com Expressões Regulares (Regex).
* **`variaveis/`**: Conceitos básicos sobre tipos de dados e declaração de variáveis.
